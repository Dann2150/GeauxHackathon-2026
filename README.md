Prompt: Create a system that helps human sustain life in extreme off-Earth environments.

Project simulator turns life in space into a survival game. Players must complete tasks to manage their vitals within a quick time frame to stay alive. By combining real life concepts with game mechanics, we make an engaging and stressful way to learn about potential problems that astronauts encounter. We used ElevenLabs API to create the dialogue and background music while using AI to help create the layout, minigames, and math behind the random events that are generated.
